# Dokumentasi Projek: Sistem Otomasi Basis Data, Persediaan, &amp; Voucher Akuntansi

## Deskripsi Projek

Projek ini berisi implementasi solusi komprehensif untuk tiga modul utama akuntansi dan manajemen persediaan berbasis PostgreSQL dan Web Full-Stack:

1. **Soal 1**: Perancangan Arsitektur Data, Normalisasi (3NF), dan Penegakan Asas Berpasangan (Double-Entry).
2. **Soal 2**: Otomasi Mutasi Persediaan, Database Trigger PL/pgSQL, dan Penanganan Concurrency (Race Condition).
3. **Soal 3**: Purwarupa Web Voucher Kas Keluar, Zero-Discrepancy Rule, Orchestration AI, serta Immutability &amp; Audit Trail (Kriptografi SHA-256).
